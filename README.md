# Arduino-Radar
Arduino ultrasonic radar using HC-SR04, servo motor and processing
Arduino Radar System

#About the Project

I built an Arduino-based radar system using an Arduino Uno, HC-SR04 ultrasonic sensor, and servo motor. The system scans different angles and measures the distance of objects. The results are displayed on a computer using Processing.

#Arduino

I connected the Arduino Uno with the HC-SR04 ultrasonic sensor and servo motor using jumper wires.

#How It Works

The servo motor rotates the ultrasonic sensor to scan different angles. The HC-SR04 measures the distance of objects, and the Arduino sends the angle and distance data to the computer through serial communication.

#Processing

I used Processing to receive the data from the Arduino and display it as a radar visualization on the computer.

#Components Used

- Arduino Uno
- HC-SR04 ultrasonic sensor
- Servo motor
- Jumper wires
- Computer
